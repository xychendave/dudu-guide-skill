## 添加素材时怎样写清楚

为外部素材记录：作品标题、作者/发布者、原始链接、适用授权、是否允许修改与再分发、需要怎样署名、检查日期。无法确认授权时先保留链接，不把素材文件提交到公开仓库。

来源支持事实，许可支持使用范围，这两件事分别核实。`source.license` 写了一个字符串，不会替你取得任何授权。

代码依赖如在后续引入，也应更新依赖与许可清单。当前工作台没有第三方 npm 运行依赖。
