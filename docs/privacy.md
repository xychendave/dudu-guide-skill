# 隐私与数据流

## 本地工作台默认行为

| 数据 | 默认存放在哪里 | 何时离开本机 |
| --- | --- | --- |
| 地点包 | 生成目录的 `pack.json` | 你选择分享、部署或发给 Agent 时 |
| 路线选择 | 当前页面内存 | 模板没有默认上传 |
| 观察与笔记 | 当前浏览器的 `localStorage` | 你导出后主动分享时 |
| Markdown / JSON 备份 | 浏览器选择的下载目录 | 你上传或发送时 |
| 复制的追问资料 | 剪贴板与页面可复制文本框 | 你粘贴并发送给外部 Agent 时 |

模板没有账号、统计脚本、远程字体、默认照片上传、GPS 请求或模型 API。开发服务器仅监听本机，限定可访问文件，不提供写入接口。页面会读取同源的 `pack.json`；来源链接由用户点击后打开。

`localStorage` 不是加密保险箱。同一电脑上的浏览器使用者、浏览器扩展与设备备份等可能影响数据访问。清理网站数据会删除记录。换端口、域名或浏览器，不会自动带走记录。

## 自己的 Agent 仍有自己的数据处理方式

Skill 只是指令与资源，不改变宿主 Agent 的存储、日志、模型服务和工具权限。使用云端模型时，发给它的资料会进入该服务；使用云端转写、识图或语音服务也是如此。Token 与服务费用由使用者自行选择的服务承担。

「本地工作台」描述界面和记录的默认位置。「完全本地推理」需要模型与相关处理也确实在本地。请按实际配置说明，不能互相替代。

## 公开发布前的范围

不要把个人记录、照片 EXIF、精确轨迹、API Key、服务器配置或完整运营数据混入地点包和 Git 历史。模板生成目录默认被仓库忽略；如果你选择把它公开，请先检查其中的 `pack.json` 与额外文件。

社区地点包可以提供公开地点资料和有来源的知识。共享观察应另设明确的分享选择、有效期和撤回机制，而不是把浏览器备份自动当公共动态。

## 开发边界

本模板适合本机运行和二次开发，不是完成所有生产需求的多人服务。添加聊天、照片、GPS 或共享功能后，需要重新说明这些数据的去向。已有 CSP 也要根据明确的新增接口审慎调整，不要直接全部放开。
