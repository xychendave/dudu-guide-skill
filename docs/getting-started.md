# 使用指南

## 选择一种开始方式

**想先看看效果**：按 [README](../README.md) 克隆仓库、生成工作台并启动本地服务。不需要配置模型。

**想让 Agent 帮忙构建**：让它读取 `skills/dudu-guide/SKILL.md`，提供想去的地方与已有资料。Agent 应先做可检查的工作台和缺口说明，再完善真实数据。

**只想获得陪逛帮助**：把地点资料、当前位置和剩余时间交给支持阅读 Skill 的 Agent。无须为了得到一条路线先安装整套网站。

## 命令说明

以下均在仓库根目录运行：

| 命令 | 用途 |
| --- | --- |
| `node skills/dudu-guide/scripts/dudu.mjs init --output output/demo` | 复制模板和虚构示例到新目录 |
| `node skills/dudu-guide/scripts/dudu.mjs init --pack path/to/pack.json --output output/place` | 使用自己准备的地点包生成 |
| `node skills/dudu-guide/scripts/dudu.mjs validate --pack output/demo/pack.json` | 校验字段、引用与来源结构 |
| `node skills/dudu-guide/scripts/dudu.mjs serve --dir output/demo --port 4173` | 在本机预览 |
| `npm test` | 运行仓库的 Node 测试 |

`path/to/pack.json` 是待替换的路径。所有输出目录均不得已存在；生成器不会覆盖已有工作台。要继续修改，直接编辑该目录的 `pack.json`、HTML、CSS 或 JavaScript。改完刷新浏览器。

生成目录包含：`index.html`、`styles.css`、`app.mjs`、`core.mjs`、`pack.json`、`LICENSE` 与 `.gitignore`。它不包含聊天后端，不需要数据库。模板更新不会自动覆盖你已经修改过的目录；升级时比较文件后合并，并先导出记录。

## 第一次试用的五分钟

1. 选择南门出发、北门离园，输入 120 分钟和 10 分钟缓冲。
2. 勾选想去的站点，生成路线。观察总时间是否包含离园。
3. 点击某站「我到了」，当前场馆与当前位置随之更新。
4. 阅读资料和观察提示。点一个追问，复制到自己的 Agent。
5. 点击「暂时没看到动物」，看看能否获得另一种观察方式。
6. 写下自己的发现，收入手帐，再导出 Markdown 和 JSON。
7. 把剩余时间改成 45 分钟，重新规划；今天已记录的站点会被排除。

默认园区是虚构的，这些操作仅验证产品流程。`seen` 是你主动记录的结果，工作台不自动识别动物，也不伪造目击。

## 模型与费用

不用模型也可以使用静态资料卡、规划和手帐。要问更多问题，将复制的内容交给自己的 Agent，按其正常模型配置和计费使用。

这份 Skill 不提供免费 Token、统一模型账号或共享 API Key。模板里没有「输入 API Key」的前端表单。如果你需要网页内对话，请阅读 [扩展架构](../skills/dudu-guide/references/architecture.md)。

## 记录如何带走

- **导出手帐 .md**：可读文字，适合编辑、排版和交给 Agent 二次整理。
- **备份 .json**：保留结构化记录，可在相同地点包 ID 的工作台导入。
- **导入备份**：与已有记录合并，不替换已有同 ID 记录。地点 ID 或版本不匹配会拒绝。

数据按浏览器网站来源存储，端口也属于来源的一部分。`127.0.0.1:4173` 与 `127.0.0.1:4174` 的记录不自动互通。换设备、换浏览器、清空网站数据之前先导出。备份可能包含私人笔记，不要默认提交到 GitHub。

## 常见问题

**页面显示「工作台未能启动」？** 请通过提供的服务器打开，不要双击 HTML 使用 `file://`。确认 `pack.json` 在生成目录中，运行 `validate` 查看错误。

**端口被占用？** 加 `--port 4174`，然后访问对应端口。换端口前按需要导出原来源的记录。

**为什么没有自动回答？** v0.1 的网页提供资料和复制提示词，模型回答在自己的 Agent 中完成。复制按钮也会展开文本框，剪贴板不可用时可以手动复制。

**为什么没有 GPS？** 模板以手动到馆为触发。定位需要用户授权、实际坐标、误差处理与触发控制，见架构扩展说明。

**为什么少安排了几个站？** 当前策略必须保留出口和缓冲，候选站还可能关闭或没有所选条件下的连接。减少其他选择、增加时间，或核实地点包；不要随意补假道路。

**为什么同日去过的地方不再安排？** 当前模板按本地日历日把有记录的站点视为已完成。如果需要同日二次到访，可以让 Agent 增加「再次到访」选项；这是明确的扩展点。

**可以手机使用吗？** 页面有响应式布局，但开发服务器只监听电脑本机。要从手机访问，需要自己部署静态目录或配置合适的设备访问方式；本仓库不默认开放局域网，也没有 PWA 离线缓存。地点包中的私人内容应先审查再部署。

**支持哪种 Agent？** 采用开放的 Skill 目录结构；实际加载方式依赖客户端。自动发现失败时直接让 Agent 读取 `SKILL.md`。可阅读文件但不能执行命令的 Agent 可以给出内容与指令，无法自动启动网页。

**可以完整复刻红山线上版吗？** 这个仓库提供方法与轻量起点。原线上产品的模型、识别、共享记录、素材、数据和服务配置并未全部开源到这里。
