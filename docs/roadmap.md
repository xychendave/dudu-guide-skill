# 共建路线图

以下是方向，不是上线承诺或已经存在的功能。具体任务以 Issues 与合并记录为准。

## v0.1：一个能用的共同起点

- [x] 通用 Dudu Skill 与逐步展开的参考文档。
- [x] 原创虚构地点包与可运行工作台。
- [x] 含出口路程与缓冲的路线估计，以及中途重排。
- [x] 场馆资料、来源、观察任务与未遇见时的替代体验。
- [x] 本地文字记录、Markdown/JSON 导出与备份合并导入。
- [x] 将资料复制给自己的 Agent 继续问答。
- [x] 红山案例、迁移指南、隐私说明与贡献流程。

## 下一步优先项

- [ ] 社区贡献的真实地点包，完成来源和路线核验。
- [ ] 同日二次到访、明确必看点、时间窗口与更好的路线取舍。
- [ ] 更多现场实测和无障碍体验反馈。
- [ ] 英文工作台和多语言内容组织。
- [ ] 可更换的手帐版式、打印样式和本地照片管理。

## 需要独立能力的扩展

- [ ] 自选模型的网页内问答适配器，含来源、超时与额度控制。
- [ ] 本地模型、语音与识图的可选接入示例。
- [ ] 用户明确启用的定位触发与 PWA 离线能力。
- [ ] 有分享选择、过期和撤回机制的共享观察服务。
- [ ] 在取得真实数据后研究拥堵/限载约束；不把估计样本包装成实测客流。

## 怎么判断改进有效

用实际任务而不是功能数量评估：游客是否知道下一步去哪，时间变化后能否离园，故事是否有来源，没看到动物时能否获得观察收获，记录是否忠实，Agent 是否在能力不足时说明缺口。

欢迎带着一个能复现的场景提交 Issue。项目不要求所有贡献都写代码。
